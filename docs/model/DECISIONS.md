# Canonical Decisions

Anything in this file is treated as accepted unless explicitly revised by the researcher.

## Research scope

- There is one central research question and one causal architecture.
- Market sedimentation is the priority object.
- Colombia 1999 is a motivating/historical case and possible empirical application, not the whole empirical strategy.
- Cobweb dynamics are a temporal supply structure, not a competing thesis.
- Equipment-loan/comodato is an extension concerning physical expansion and vertical control, not the central mechanism.
- ESG is a possible generalization to credence attributes, not a competing thesis.

## Theory

- The stochastic-memory model is the demand microfoundation.
- Consumers with low information do not prefer low quality by assumption.
- Choice is optimal conditional on the consumer's memory/information state and the local optimum they face.
- Memory stochasticity is intrinsic to the representation/decision process and should not be replaced by ad hoc case-specific parameters.
- The model should remain parsimonious: do not create a parameter for every empirical case.
- Information infrastructure connects demand and supply by making process/quality attributes recognizable and credible.
- Certification must be treated as informative only to the extent that it is linked to verifiable attributes/processes.

## Market structure

- Keep the broad segmentation distinction parsimonious: commodity, specialty, and luxury/COE when needed for the empirical discussion.
- COE is an institutional reference / selected quality frontier, not an estimate of the total specialty market.
- High auction price alone is not evidence of market sedimentation.

## Empirical strategy

- Current empirical object: `appearance → remuneration → reproduction`.
- Separate:
  1. direct process information at lot level;
  2. process classification implied by event/category rules;
  3. national/institutional regime information.
- Never impute Washed, Natural, Experimental or another process merely for convenience.
- Missing information remains missing unless supported by documentary/institutional evidence.
- Pre-2018 data can characterize institutional regimes/baselines where lot-level process coverage is insufficient.
- COE data alone cannot show that all producers changed behavior because of COE.
- External specialty-market evidence is needed to assess diffusion beyond the selected auction environment.
- Define econometric windows and shocks only after data-coverage and first-appearance audits are complete.

## Working discipline

- Any new theoretical mechanism must be labeled `PROPOSAL — NOT YET ACCEPTED`.
- Any new parameter must include a justification for why an existing parameter cannot represent the mechanism.
- Any empirical variable definition must identify its source and whether it is direct, inferred from event rules, regime-level, or constructed.
- No AI-generated claim enters the canonical state without verification.

## Notation discipline

- Identical symbols must not be used for economically different objects across the demand and producer models.
- A canonical symbol dictionary governs notation in the integrated model.
- Renaming symbols for clarity does not change the economic content of the model.
- Any substantive change in mechanism, parameter interpretation, behavioral rule or empirical definition remains subject to explicit acceptance.

## Demand-model closure discipline

- The existing stochastic-memory mechanism must be closed before introducing any additional stochastic-choice mechanism.
- Non-degenerate choice probabilities conditional on memory must not be generated by adding taste shocks, logit/probit errors or new choice parameters unless the existing memory structure is shown to be insufficient and such an extension is explicitly accepted.


## Canonical interpretation of consumer memory state

- `M` is a common decision-relevant state across consumers.
- Consumer heterogeneity affects the path by which consumers reach different memory states.
- Conditional on a given current memory state `M`, the binary choice rule is deterministic.
- Consumer heterogeneity is generated through stochastic memory formation, heterogeneous updating costs, initial conditions and learning paths, rather than through an additional random-utility or taste-shock term.
- `F_t(M)` remains the aggregate distribution of consumer memory states and is sufficient for aggregate binary demand.
- `Pr(A = H | M)` in the binary model is interpreted as a degenerate conditional probability implied by the deterministic choice rule.
- No logit, probit, random-utility shock or additional stochastic-choice parameter is introduced.

## Semi-separation and quasi-pooling

- Semi-separation refers to persistent positive demand for both alternatives:
  `0 < F_t(R_H) < 1`.
- Exact overlap of H- and L-choosers at the identical memory state is not required and is incompatible with the canonical deterministic choice rule.
- The previous expression `F^H(M) ∩ F^L(M) != empty` must therefore be revised.
- Quasi-pooling will refer to the absence of a separating gap around the differentiation threshold, rather than exact overlap at an identical memory state.
